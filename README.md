# Тема 8. Синтаксис async/await і пагінація. Домашня робота

Фіналізація застосунку пошуку зображень із попередньої домашньої роботи:
рефакторинг на `axios` + `async/await`, пагінація з кнопкою **Load more**,
обробка кінця колекції та плавне прокручування сторінки.

## Загальні вимоги

- Репозиторій: `goit-advancedjs-hw-04`.
- Збірка: [Vite](https://vitejs.dev/). Рекомендовано використовувати
  [готовий шаблон](https://github.com/goitacademy/vanilla-app-template).
- HTTP-запити: бібліотека [axios](https://axios-http.com/).
- Асинхронний код: синтаксис `async/await`.
- Код відформатований за допомогою `Prettier`.
- У консолі живої сторінки немає помилок, попереджень і `console.log`.
- Стилізація за [макетом](https://www.figma.com/file/m8k9NQV7qZrtYDCvxfD68B/%D0%94%D0%97-JavaScript?type=design&node-id=3-1010&mode=design&t=eCh8cUwdfWOakuAr-0)
  (або власні стилі).

- Два посилання: на вихідні файли і на робочу сторінку на **GitHub Pages**.

## Структура коду

Код організований модульно, з використанням `export/import`.

### `js/pixabay-api.js` — HTTP-запити

- `getImagesByQuery(query, page)` — приймає `query` (пошукове слово, рядок) та
  `page` (номер сторінки, число), виконує HTTP-запит і повертає властивість
  `data` з відповіді.

### `js/render-functions.js` — відображення інтерфейсу

Тут створюється екземпляр `SimpleLightbox` і зберігаються функції (усі нічого
не повертають):

| Функція                | Що робить                                                                                       |
| ---------------------- | ----------------------------------------------------------------------------------------------- |
| `createGallery(images)` | Створює розмітку галереї з масиву `images`, додає її в контейнер і викликає `lightbox.refresh()` |
| `clearGallery()`       | Очищає вміст контейнера галереї                                                                 |
| `showLoader()`         | Додає клас для відображення лоадера                                                             |
| `hideLoader()`         | Прибирає клас для відображення лоадера                                                          |
| `showLoadMoreButton()` | Додає клас для відображення кнопки **Load more**                                                |
| `hideLoadMoreButton()` | Прибирає клас для відображення кнопки **Load more**                                             |

### `main.js` — логіка застосунку

- Уся логіка роботи додатка.
- Виклики нотифікацій **iziToast**.
- Усі перевірки довжини масиву в отриманій відповіді.
- Логіка прокручування сторінки (scroll).
- Імпортує функції з `pixabay-api.js` та `render-functions.js` і викликає їх у
  відповідний момент.

## Завдання. Пошук зображень

Використай код із попередньої домашньої роботи та доповни його новим
функціоналом.

### 1. Рефакторинг

- Підключи [axios](https://axios-http.com/) і заміни ним використання `fetch`.
- Перепиши всі асинхронні запити на синтаксис `async/await`.

### 2. Пагінація

Pixabay API підтримує параметри `page` і `per_page`.

- У кожній відповіді має приходити **15** зображень (`per_page: 15`, за
  замовчуванням 20).
- Початкове значення `page` — `1`.
- З кожним наступним запитом `page` збільшується на `1`.
- При пошуку за новим ключовим словом `page` скидається до `1`.

### 3. Кнопка Load more

- Додай в HTML після галереї кнопку з текстом `Load more`.
- За кліком виконується запит за наступною групою зображень, і розмітка
  **додається** до вже наявних елементів галереї.
- Пошукове слово при сабміті форми зберігається в глобальну змінну, щоб
  використовувати його для наступних запитів.
- Поки в галереї немає зображень — кнопка прихована.
- Коли зображення з'являються — кнопка відображається під галереєю.
- При повторному сабміті форми кнопка спочатку ховається, а після отримання
  результатів знову показується за потреби.
- Індикатор завантаження розміщується **під** кнопкою Load more.

### 4. Кінець колекції

- Бекенд повертає `totalHits` — загальну кількість зображень за запитом (для
  безкоштовного акаунту).
- Коли користувач дійшов до кінця колекції: ховай кнопку **Load more** і покажи
  повідомлення:

  ```
  We're sorry, but you've reached the end of search results.
  ```

### 5. Прокручування сторінки

Після завантаження та відмальовки кожної наступної групи зображень сторінка
плавно прокручується:

1. Отримай висоту однієї картки галереї через
   [`getBoundingClientRect()`](https://developer.mozilla.org/en-US/docs/Web/API/Element/getBoundingClientRect).
2. Прокрути сторінку на **дві висоти картки** за допомогою
   [`window.scrollBy()`](https://developer.mozilla.org/en-US/docs/Web/API/Window/scrollBy)
   з `behavior: "smooth"`.
